# يومي

تطبيق شخصي عربي للهاتف واللابتوب: [افتحي يومي](https://ghadahelou859-dot.github.io/yomi-planner/).

## الميزات

مهام يومية مع بدء وانتهاء اختياريين أو إيقاف، سجل إنجاز لكل تاريخ، استثناء مهام الصلاة خلال فترة الدورة المسجّلة، ويوم راحة خارج النسب. أذكار بهدف يومي وعدّاد مستقل ومجاميع يومية وشهرية وسنوية. متابعة قراءة تتذكر آخر صفحة وتعرض الصفحة التالية. شرب المي بالمل أو اللتر مع هدف تختارينه ورسوم بيانية. ثلاث أولويات ومراجعة لليوم والمزاج والطاقة والحركة. كذلك إنجازات الشغل، الدخل والمصاريف والديون، التذكيرات والملاحظات وتقارير ورسوم إنجاز ونبتة تكبر بالخطوات المسجّلة.

## الحفظ والمزامنة

تُحفظ البيانات محليًا، وتتزامن مع حسابك على Supabase عند تسجيل الدخول إذا كانت إعدادات المشروع المنشور متاحة. افتحي الحساب نفسه على جهازك الآخر، وانتظري علامة «محفوظ في الحساب». يُخزن الحساب سجلاته في صف خاص به مع سياسات RLS. عند اختلاف بيانات الجهاز والحساب يظهر اختيار النسخة التي تريدين اعتمادها؛ صدّري نسخة احتياطية JSON قبل استبدال أي نسخة.

الرقم من رقمين قفل بسيط محلي للجهاز، وليس تشفيرًا للبيانات. استخدمي جهازك الشخصي، ولا تشاركي بيانات الدخول أو ملف النسخة الاحتياطية. إعدادات Supabase المنشورة تحتوي المفتاح القابل للنشر فقط، وليس مفتاحًا سريًا.

## حدود حالية

التذكيرات تظهر أثناء فتح الصفحة فقط. توقع الدورة تقديري وليس تشخيصًا طبيًا. تتم مزامنة ملف البيانات كاملًا؛ تجنّبي تعديل البيانات على الجهازين في اللحظة نفسها. قد يظهر تعارض إذا تغيّر الحساب قبل الحفظ.
