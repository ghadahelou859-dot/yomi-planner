# يومي
تطبيق شخصي عربي يعمل من ملف `index.html` أو من GitHub Pages.

## التشغيل
افتح `index.html` في المتصفح، أو ارفع محتويات هذا المجلد إلى مستودع GitHub خاص وانشرها عبر Pages إذا رغبتِ. نشر الملفات لا ينشر بياناتك: التسجيلات تحفظ في `localStorage` على جهازك فقط.

## الميزات
مهام شخصية وشغل، إنجازات، مصاريف بالشيكل، ديون لك وعليك مع دفعات جزئية، تذكيرات أثناء فتح الصفحة، ملاحظات، سجل دورة شهرية وتقدير موعدها من الفواصل المتاحة، يوم راحة، رسوم إنجاز، ونسخ احتياطية JSON.

## حدود مهمة
التذكيرات تعمل داخل الصفحة المفتوحة فقط؛ لا توجد إشعارات عندما تكون مغلقة. بيانات الدورة والمصاريف ليست مشفرة داخل المتصفح، لذلك استخدمي جهازًا شخصيًا واحفظي النسخة الاحتياطية في مكان آمن. مسح بيانات المتصفح أو استخدام جهاز آخر لا ينقل السجلات تلقائيًا. التقدير الشهري ليس نصيحة طبية. النبتة رمز تحفيزي؛ يتغير مظهرها عند انقطاع النشاط ثلاثة أيام، ولا يحذف أي تقدم.

## قفل الرقمين
عند أول فتح تختارين رقمين. يُخزن القفل محليًا على هذا الجهاز، وهو قفل بسيط للواجهة وليس تشفيرًا أو حماية قوية. إذا نسيتِ الرقم، فلا توجد آلية استعادة مدمجة. النسخة الاحتياطية تحتوي بياناتك ولا تحتوي الرقم السري.

## مزامنة Supabase (قيد الإعداد)
شغّل `supabase/schema.sql` في مشروع Supabase مستقل، ثم انسخ `supabase-config.example.js` إلى `supabase-config.js` وضع عنوان المشروع والمفتاح القابل للنشر فقط. سجّل دخولك بنفس البريد وكلمة المرور على الجهازين. عند أول دخول من هاتفك، وافقي على رفع البيانات المحلية. عند دخول اللابتوب اختاري بيانات الحساب إذا كان عليه بيانات تجريبية. لا تضعي مفتاح `service_role` أو أي مفتاح سري في المستودع. ميزة المزامنة لا تصبح فعالة قبل إنشاء المشروع وتطبيق المخطط وإعداد الملف. النسخة الحالية تحمي الصفوف بسياسات RLS؛ التزامن بين جهازين أثناء التحرير المتزامن يحتاج اختبارًا إضافيًا.
